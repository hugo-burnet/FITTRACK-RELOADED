# Cadence impact

`rep-impact.wav` is derived from **Sound Design Elements Impact SFX PS 036**
by AudioPapkin:

- Source: https://freesound.org/people/AudioPapkin/sounds/812702/
- License: CC0 1.0 (public domain dedication)
- License text: https://creativecommons.org/publicdomain/zero/1.0/

FitTrack uses a 1.05-second cut of the source. The tail is faded and the result
is normalized to -1 dBFS. Two quiet, delayed low-frequency layers (58 to 34 Hz
and 104 to 62 Hz) add weight behind the original attack without adding a click
or high-frequency content.

# Screen glitch (Cyber theme)

`screen-glitch.mp3` plays when a screen arrives in the Cyber theme. It is mixed by
`scripts/cyber-sounds/mix.py` from **Kenney** packs (Interface Sounds `glitch_001` to `glitch_004`,
Sci-Fi Sounds `computerNoise_002`), all **CC0 1.0** (see `scripts/cyber-sounds/sources/`): one burst
per frame of the on-screen tear, 0.32 s, about 3 dB under the cadence impact.
