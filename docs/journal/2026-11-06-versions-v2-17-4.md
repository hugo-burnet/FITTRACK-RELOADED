# v2.17.4 — maintenance Windows et fondations homelab

Publication demandée par le propriétaire le 6 novembre 2026 : pousser les deux
dépôts, mettre la documentation à jour et versionner l'application.

## Dans l'application

Le module pur `cyberGlitch.ts` est renommé `cyberGlitchRules.ts` pour éviter la
collision avec le composant `CyberGlitch.tsx` sur les systèmes de fichiers
insensibles à la casse. Aucun changement du schéma de données ni nouvelle
fonction de synchronisation dans cette version. L'APK conserve `com.fittrack.app`
et la signature de distribution existante : mise à jour par-dessus l'installation.

## Dans le dépôt

Un backend Django local ajoute la séparation des comptes, les révisions
atomiques et conflits explicites, l'idempotence, les sessions liées à une
génération externe et la configuration fermée par défaut. Un export cohérent
SQLite inclut les transactions validées en WAL, produit une base autonome et
un manifeste avec empreinte. Les dépendances Python sont verrouillées avec
leurs empreintes et un workflow CI teste le backend sous Linux.

**Ce backend n'est pas prêt à être exposé.** Les parcours d'authentification,
invitations, récupération/MFA, limites d'abus et de stockage, restauration
complète et clients web/Android restent à livrer. Aucun accès public homelab
n'est activé par cette release. Les sites GitHub Pages restent en service.

## Vérifications

Typecheck, lint et build passent. La suite frontend complète passe avec un
worker : 3 862 réussites, un test ignoré. Le backend compte 34 tests : sous
Windows 32 réussissent et deux contrôles POSIX sont ignorés ; ces contrôles
passent dans les tests d'export exécutés sous Linux. La recette téléphone
de mise à jour et de conservation des données reste à faire par le propriétaire.

## Publication et suivi

Le tag `v2.17.4` déclenche le workflow Android qui vérifie le frontend,
construit l'APK avec la clé de distribution et publie
[FitTrack Android v2.17.4](https://github.com/hugo-burnet/FITTRACK-RELOADED/releases/tag/v2.17.4).
