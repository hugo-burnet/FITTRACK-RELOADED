# Splits

## Résumé

<!-- editorial -->
Le split est une conséquence du volume et de la fréquence, pas un paramètre indépendant.

## Fiches

<!-- factual: row:cand.e1.ed8c3905c41098c0 -->
Affirmation principale : Full-body et split produisent des gains similaires quand le volume est égalisé.

<!-- factual: row:cand.e1.ed8c3905c41098c0 -->
Confiance : Élevé

<!-- factual: row:cand.e1.ed8c3905c41098c0 -->
Population : 14 études, 392 adultes sains

<!-- factual: row:cand.e1.ed8c3905c41098c0 -->
Sources principales : Ramos-Campo et al., 2024

<!-- factual: row:cand.e1.ed8c3905c41098c0 -->
Type de preuve : Revue systématique/méta-analyse

<!-- factual: row:cand.e1.ed8c3905c41098c0 -->
Contradictions / nuances : Peu de données sur volumes très élevés, compétiteurs avancés ou splits précis PPL/body-part.

<!-- factual: row:cand.e1.ed8c3905c41098c0 -->
Limites : Caractéristiques détaillées hétérogènes; peu de sites musculaires par comparaison.

<!-- factual: row:cand.e1.ed8c3905c41098c0 -->
Interprétation pratique : Choisir selon agenda, préférence, durée de séance et distribution du volume.

<!-- factual: row:cand.e1.ed8c3905c41098c0 -->
Ce qu’on ne peut PAS conclure : Que tous les splits sont identiques si adhésion/fréquence/volume diffèrent.

<!-- factual: row:cand.e1.5fd9781ca4b7df20 -->
Affirmation principale : Upper/lower, PPL et body-part split sont des structures logistiques, non des stimuli physiologiques autonomes.

<!-- factual: row:cand.e1.5fd9781ca4b7df20 -->
Confiance : Élevé par inférence

<!-- factual: row:cand.e1.5fd9781ca4b7df20 -->
Population : Adultes sains

<!-- factual: row:cand.e1.5fd9781ca4b7df20 -->
Sources principales : Ramos-Campo et al., 2024; Schoenfeld et al., 2019

<!-- factual: row:cand.e1.5fd9781ca4b7df20 -->
Type de preuve : Méta-analyse split + fréquence

<!-- factual: row:cand.e1.5fd9781ca4b7df20 -->
Contradictions / nuances : La structure influence indirectement durée, fatigue, fréquence et adhésion.

<!-- factual: row:cand.e1.5fd9781ca4b7df20 -->
Limites : Peu de comparaisons directes entre tous les noms de splits.

<!-- factual: row:cand.e1.5fd9781ca4b7df20 -->
Interprétation pratique : Évaluer les variables réelles : séries/muscle/semaine, séances/muscle, ordre, repos, récupération.

<!-- factual: row:cand.e1.5fd9781ca4b7df20 -->
Ce qu’on ne peut PAS conclure : Qu’un PPL est « avancé » ou qu’un full-body est seulement pour débutants.
