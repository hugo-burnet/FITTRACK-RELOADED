# Sélection et variation

## Résumé

<!-- editorial -->
Ces fiches traitent la variation comme une décision de programmation, distincte du choix biomécanique d’un exercice.

## Fiches

<!-- factual: row:cand.e1.b2513d2c6be2fda4 -->
Affirmation principale : Machines et poids libres produisent une hypertrophie similaire; la force est spécifique au mode testé.

<!-- factual: row:cand.e1.b2513d2c6be2fda4 -->
Confiance : Élevé pour hypertrophie moyenne; modéré pour muscles précis

<!-- factual: row:cand.e1.b2513d2c6be2fda4 -->
Population : 13 études, 1 016 adultes; entraînés/non-entraînés; pas d’athlètes d’élite

<!-- factual: row:cand.e1.b2513d2c6be2fda4 -->
Sources principales : Haugen et al., 2023

<!-- factual: row:cand.e1.b2513d2c6be2fda4 -->
Type de preuve : Revue systématique/méta-analyse

<!-- factual: row:cand.e1.b2513d2c6be2fda4 -->
Contradictions / nuances : Mesures d’hypertrophie seulement dans une partie des études; exercices non anatomiquement identiques.

<!-- factual: row:cand.e1.b2513d2c6be2fda4 -->
Limites : Interventions ~9 semaines; cinq-six études hypertrophie.

<!-- factual: row:cand.e1.b2513d2c6be2fda4 -->
Interprétation pratique : Choisir selon stabilité, confort, progression, équipement et spécificité; combiner si utile.

<!-- factual: row:cand.e1.b2513d2c6be2fda4 -->
Ce qu’on ne peut PAS conclure : Que les poids libres sont plus « fonctionnels » donc plus hypertrophiques; que les machines éliminent toute stabilisation pertinente.

<!-- factual: row:cand.e1.644f5df177a80f4f -->
Affirmation principale : Mono- et polyarticulaires peuvent hypertrophier les muscles des membres; l’isolation ajoute surtout une couverture spécifique.

<!-- factual: row:cand.e1.644f5df177a80f4f -->
Confiance : Modéré

<!-- factual: row:cand.e1.644f5df177a80f4f -->
Population : Jeunes adultes, souvent hommes

<!-- factual: row:cand.e1.644f5df177a80f4f -->
Sources principales : Rosa et al., 2023; Gentil et al., 2015

<!-- factual: row:cand.e1.644f5df177a80f4f -->
Type de preuve : Revue systématique/méta-analyse; RCT

<!-- factual: row:cand.e1.644f5df177a80f4f -->
Contradictions / nuances : Certains essais trouvent davantage de fléchisseurs avec curl que rowing; d’autres aucun ajout aux composés.

<!-- factual: row:cand.e1.644f5df177a80f4f -->
Limites : Mesures locales, peu d’études, choix précis des exercices.

<!-- factual: row:cand.e1.644f5df177a80f4f -->
Interprétation pratique : Utiliser composés pour efficacité globale; ajouter isolation lorsque le muscle est prioritaire, peu stimulé ou limité par un synergiste.

<!-- factual: row:cand.e1.644f5df177a80f4f -->
Ce qu’on ne peut PAS conclure : Que les composés suffisent toujours à tous les chefs musculaires; que chaque composé compte comme une série complète pour tous les synergistes.

<!-- factual: row:cand.e1.19b9467e3f9bc113 -->
Affirmation principale : La stabilité peut améliorer la capacité à approcher l’échec du muscle cible, mais n’est pas une fin en soi.

<!-- factual: row:cand.e1.19b9467e3f9bc113 -->
Confiance : Faible (mécanistique/pratique)

<!-- factual: row:cand.e1.19b9467e3f9bc113 -->
Population : Tous

<!-- factual: row:cand.e1.19b9467e3f9bc113 -->
Sources principales : IUSCA, 2021; Androulakis Korakakis et al., 2023

<!-- factual: row:cand.e1.19b9467e3f9bc113 -->
Type de preuve : Consensus; revue narrative

<!-- factual: row:cand.e1.19b9467e3f9bc113 -->
Contradictions / nuances : L’instabilité peut être spécifique à un sport ou à un objectif de contrôle.

<!-- factual: row:cand.e1.19b9467e3f9bc113 -->
Limites : Peu de données longitudinales directes.

<!-- factual: row:cand.e1.19b9467e3f9bc113 -->
Interprétation pratique : Pour hypertrophie, préférer une stabilité suffisante afin que le muscle cible, non l’équilibre, limite la série.

<!-- factual: row:cand.e1.19b9467e3f9bc113 -->
Ce qu’on ne peut PAS conclure : Qu’une machine est toujours supérieure ou qu’un exercice instable ne peut jamais hypertrophier.

<!-- factual: row:cand.e1.ff7e49aef32bd19f -->
Affirmation principale : Une variation systématique peut élargir l’hypertrophie régionale; une variation aléatoire excessive n’est pas supérieure.

<!-- factual: row:cand.e1.ff7e49aef32bd19f -->
Confiance : Modéré

<!-- factual: row:cand.e1.ff7e49aef32bd19f -->
Population : 241 jeunes hommes dans la revue; un RCT de 21 hommes entraînés

<!-- factual: row:cand.e1.ff7e49aef32bd19f -->
Sources principales : Kassiano et al., 2022; Baz-Valle et al., 2019

<!-- factual: row:cand.e1.ff7e49aef32bd19f -->
Type de preuve : Revue systématique; RCT

<!-- factual: row:cand.e1.ff7e49aef32bd19f -->
Contradictions / nuances : Le RCT randomisant exercices à chaque séance trouve hypertrophie/force similaires, motivation un peu meilleure.

<!-- factual: row:cand.e1.ff7e49aef32bd19f -->
Limites : Petits échantillons, peu de femmes, mesures régionales limitées.

<!-- factual: row:cand.e1.ff7e49aef32bd19f -->
Interprétation pratique : Conserver des exercices principaux assez longtemps pour progresser; varier angles/exercices de façon planifiée, non compulsive.

<!-- factual: row:cand.e1.ff7e49aef32bd19f -->
Ce qu’on ne peut PAS conclure : Une fréquence optimale de rotation; que « confusion musculaire » améliore la croissance.

<!-- factual: row:cand.e1.399c8c3c09cc32ef -->
Affirmation principale : Des exercices biomécaniquement redondants peuvent ajouter fatigue/temps sans couvrir une nouvelle fonction ou longueur.

<!-- factual: row:cand.e1.399c8c3c09cc32ef -->
Confiance : Faible à modéré

<!-- factual: row:cand.e1.399c8c3c09cc32ef -->
Population : Tous

<!-- factual: row:cand.e1.399c8c3c09cc32ef -->
Sources principales : Kassiano et al., 2022

<!-- factual: row:cand.e1.399c8c3c09cc32ef -->
Type de preuve : Revue systématique + raisonnement biomécanique

<!-- factual: row:cand.e1.399c8c3c09cc32ef -->
Contradictions / nuances : Deux exercices proches peuvent différer en confort, profil de résistance ou région stimulée.

<!-- factual: row:cand.e1.399c8c3c09cc32ef -->
Limites : « Redondance » rarement testée directement.

<!-- factual: row:cand.e1.399c8c3c09cc32ef -->
Interprétation pratique : Sélectionner peu d’exercices complémentaires couvrant fonctions, longueurs et tolérance; éviter les doublons sans justification.

<!-- factual: row:cand.e1.399c8c3c09cc32ef -->
Ce qu’on ne peut PAS conclure : Qu’une liste fixe d’exercices est universellement optimale.
