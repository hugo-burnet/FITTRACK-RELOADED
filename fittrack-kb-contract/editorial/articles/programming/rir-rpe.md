# Proximité de l’échec, RIR et RPE

## Résumé

<!-- editorial -->
FitTrack permet de masquer le RPE. Ces fiches disent ce que la littérature attribue réellement à la proximité de l’échec.

## Fiches

<!-- factual: row:cand.e1.8db5f524749eb66e -->
Affirmation principale : L’échec momentané n’est pas nécessaire pour hypertrophier.

<!-- factual: row:cand.e1.8db5f524749eb66e -->
Confiance : Élevé

<!-- factual: row:cand.e1.8db5f524749eb66e -->
Population : Jeunes adultes; surtout non-entraînés, quelques entraînés

<!-- factual: row:cand.e1.8db5f524749eb66e -->
Sources principales : Grgic et al., 2022; Refalo et al., 2023; ACSM, 2026

<!-- factual: row:cand.e1.8db5f524749eb66e -->
Type de preuve : Méta-analyses; position stand

<!-- factual: row:cand.e1.8db5f524749eb66e -->
Contradictions / nuances : Les définitions du non-échec et le volume diffèrent; les charges légères pourraient nécessiter davantage de proximité.

<!-- factual: row:cand.e1.8db5f524749eb66e -->
Limites : Peu de comparaisons à RIR précisément contrôlé; faible puissance.

<!-- factual: row:cand.e1.8db5f524749eb66e -->
Interprétation pratique : Programmer la majorité des séries à ~1–4 RIR selon exercice, charge et phase; l’échec est une option, pas une règle.

<!-- factual: row:cand.e1.8db5f524749eb66e -->
Ce qu’on ne peut PAS conclure : Que 3 RIR est exactement optimal; que toutes les séries à 5+ RIR sont inefficaces.

<!-- factual: row:cand.e1.fcd738578c7d8573 -->
Affirmation principale : Se rapprocher de l’échec semble augmenter le stimulus jusqu’à une zone où les bénéfices supplémentaires deviennent faibles et la fatigue augmente.

<!-- factual: row:cand.e1.fcd738578c7d8573 -->
Confiance : Modéré pour la tendance; faible pour le seuil

<!-- factual: row:cand.e1.fcd738578c7d8573 -->
Population : Adultes sains, entraînés/non-entraînés

<!-- factual: row:cand.e1.fcd738578c7d8573 -->
Sources principales : Refalo et al., 2023; Ruple et al., 2023

<!-- factual: row:cand.e1.fcd738578c7d8573 -->
Type de preuve : Méta-analyse; petit RCT

<!-- factual: row:cand.e1.fcd738578c7d8573 -->
Contradictions / nuances : Le RCT 0–1 vs 4–6 RIR chez 19 entraînés sur 5 semaines n’a pas montré un avantage hypertrophique clair; durée courte.

<!-- factual: row:cand.e1.fcd738578c7d8573 -->
Limites : RIR déclaré peut être erroné; interaction charge-exercice-volume.

<!-- factual: row:cand.e1.fcd738578c7d8573 -->
Interprétation pratique : Approcher davantage l’échec sur isolation/machines et charges légères; garder plus de marge sur polyarticulaires lourds ou gros volume.

<!-- factual: row:cand.e1.fcd738578c7d8573 -->
Ce qu’on ne peut PAS conclure : Une frontière universelle entre « série stimulante » et « série inutile ».

<!-- factual: row:cand.e1.75f6b29bb58c259c -->
Affirmation principale : L’échec augmente fatigue neuromusculaire, inconfort et temps de récupération.

<!-- factual: row:cand.e1.75f6b29bb58c259c -->
Confiance : Élevé pour l’aigu; modéré pour impact chronique

<!-- factual: row:cand.e1.75f6b29bb58c259c -->
Population : Hommes et femmes entraînés; études aiguës souvent petites

<!-- factual: row:cand.e1.75f6b29bb58c259c -->
Sources principales : Refalo et al., 2023; Morán-Navarro et al., 2017

<!-- factual: row:cand.e1.75f6b29bb58c259c -->
Type de preuve : Crossover randomisé; étude aiguë

<!-- factual: row:cand.e1.75f6b29bb58c259c -->
Contradictions / nuances : Fatigue dépend du nombre de séries, charge, exercice et volume égalisé.

<!-- factual: row:cand.e1.75f6b29bb58c259c -->
Limites : Les marqueurs aigus ne prédisent pas directement l’hypertrophie.

<!-- factual: row:cand.e1.75f6b29bb58c259c -->
Interprétation pratique : Réserver l’échec à des séries ciblées, souvent dernière série ou isolation stable, lorsque le coût n’altère pas la suite.

<!-- factual: row:cand.e1.75f6b29bb58c259c -->
Ce qu’on ne peut PAS conclure : Que l’échec est dangereux en soi ou qu’il empêche toute récupération en 48 h.

<!-- factual: row:cand.e1.724d4ce2e01b6bd2 -->
Affirmation principale : L’estimation du RIR est imparfaite, surtout chez débutants et loin de l’échec.

<!-- factual: row:cand.e1.724d4ce2e01b6bd2 -->
Confiance : Élevé

<!-- factual: row:cand.e1.724d4ce2e01b6bd2 -->
Population : 141 pratiquants, hommes/femmes, novices à experts

<!-- factual: row:cand.e1.724d4ce2e01b6bd2 -->
Sources principales : Steele et al., 2017

<!-- factual: row:cand.e1.724d4ce2e01b6bd2 -->
Type de preuve : Validation observationnelle

<!-- factual: row:cand.e1.724d4ce2e01b6bd2 -->
Contradictions / nuances : L’expérience améliore la précision sans la rendre parfaite.

<!-- factual: row:cand.e1.724d4ce2e01b6bd2 -->
Limites : Machines et habitudes personnelles; une séance.

<!-- factual: row:cand.e1.724d4ce2e01b6bd2 -->
Interprétation pratique : Calibrer périodiquement avec une série sûre à l’échec; utiliser plages, vitesse et historique plutôt qu’un RIR comme vérité exacte.

<!-- factual: row:cand.e1.724d4ce2e01b6bd2 -->
Ce qu’on ne peut PAS conclure : Qu’un RIR auto-déclaré équivaut à une mesure objective.
