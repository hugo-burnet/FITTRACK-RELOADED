# Ordre des exercices

## Résumé

<!-- editorial -->
L’ordre des exercices est verrouillable dans l’éditeur de routine. Ces fiches disent ce qu’il produit.

## Fiches

<!-- factual: row:cand.e1.0e75def084556a94 -->
Affirmation principale : L’ordre polyarticulaire→isolation versus inverse ne change pas clairement l’hypertrophie moyenne.

<!-- factual: row:cand.e1.0e75def084556a94 -->
Confiance : Modéré

<!-- factual: row:cand.e1.0e75def084556a94 -->
Population : 11 études, caractéristiques variables

<!-- factual: row:cand.e1.0e75def084556a94 -->
Sources principales : Nunes et al., 2021

<!-- factual: row:cand.e1.0e75def084556a94 -->
Type de preuve : Revue systématique/méta-analyse

<!-- factual: row:cand.e1.0e75def084556a94 -->
Contradictions / nuances : Peu de mesures directes d’hypertrophie; muscles prioritaires spécifiques peu étudiés.

<!-- factual: row:cand.e1.0e75def084556a94 -->
Limites : Taille de littérature réduite; certaines mesures indirectes.

<!-- factual: row:cand.e1.0e75def084556a94 -->
Interprétation pratique : Choisir l’ordre selon priorité, sécurité et performance.

<!-- factual: row:cand.e1.0e75def084556a94 -->
Ce qu’on ne peut PAS conclure : Qu’un ordre est universellement supérieur pour la masse.

<!-- factual: row:cand.e1.326fb197fbf6fdb2 -->
Affirmation principale : Les exercices placés en premier gagnent généralement davantage en force spécifique.

<!-- factual: row:cand.e1.326fb197fbf6fdb2 -->
Confiance : Élevé

<!-- factual: row:cand.e1.326fb197fbf6fdb2 -->
Population : Adultes sains

<!-- factual: row:cand.e1.326fb197fbf6fdb2 -->
Sources principales : Nunes et al., 2021

<!-- factual: row:cand.e1.326fb197fbf6fdb2 -->
Type de preuve : Méta-analyse

<!-- factual: row:cand.e1.326fb197fbf6fdb2 -->
Contradictions / nuances : L’effet global tous tests confondus est nul; avantage spécifique au type placé tôt.

<!-- factual: row:cand.e1.326fb197fbf6fdb2 -->
Limites : Force ≠ hypertrophie; apprentissage du test.

<!-- factual: row:cand.e1.326fb197fbf6fdb2 -->
Interprétation pratique : Placer d’abord le mouvement ou muscle prioritaire, surtout si force et qualité technique comptent.

<!-- factual: row:cand.e1.326fb197fbf6fdb2 -->
Ce qu’on ne peut PAS conclure : Que tous les exercices composés doivent toujours passer en premier.

<!-- factual: row:cand.e1.160633733416fd44 -->
Affirmation principale : La fatigue locale et systémique d’un exercice précoce peut réduire la charge/répétitions suivantes.

<!-- factual: row:cand.e1.160633733416fd44 -->
Confiance : Élevé pour aigu; faible pour effet hypertrophique chronique

<!-- factual: row:cand.e1.160633733416fd44 -->
Population : Tous

<!-- factual: row:cand.e1.160633733416fd44 -->
Sources principales : Sousa et al., 2024

<!-- factual: row:cand.e1.160633733416fd44 -->
Type de preuve : Revue narrative de récupération

<!-- factual: row:cand.e1.160633733416fd44 -->
Contradictions / nuances : Pré-fatigue peut modifier le muscle limitant, sans avantage hypertrophique prouvé.

<!-- factual: row:cand.e1.160633733416fd44 -->
Limites : Peu de données longitudinales ciblées.

<!-- factual: row:cand.e1.160633733416fd44 -->
Interprétation pratique : Éviter de fatiguer un synergiste indispensable avant un exercice prioritaire sauf objectif explicite.

<!-- factual: row:cand.e1.160633733416fd44 -->
Ce qu’on ne peut PAS conclure : Que la pré-fatigue « isole » nécessairement mieux ou augmente la croissance.
