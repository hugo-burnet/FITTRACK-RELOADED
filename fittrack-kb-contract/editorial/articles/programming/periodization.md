# Périodisation

## Résumé

<!-- editorial -->
Les programmes multi-semaines de FitTrack organisent des routines ; ces fiches disent ce que la périodisation apporte, et ce qu’elle n’apporte pas.

## Fiches

<!-- factual: row:cand.e1.61bf7ced3b984f5e -->
Affirmation principale : À volume égal, périodisation linéaire et ondulatoire produisent une hypertrophie similaire.

<!-- factual: row:cand.e1.61bf7ced3b984f5e -->
Confiance : Modéré

<!-- factual: row:cand.e1.61bf7ced3b984f5e -->
Population : 417 participants, majorité jeunes non-entraînés; une étude entraînée

<!-- factual: row:cand.e1.61bf7ced3b984f5e -->
Sources principales : Grgic et al., 2017; Moesgaard et al., 2022

<!-- factual: row:cand.e1.61bf7ced3b984f5e -->
Type de preuve : Méta-analyses

<!-- factual: row:cand.e1.61bf7ced3b984f5e -->
Contradictions / nuances : Certaines analyses favorisent périodisation pour force, surtout entraînés; hypertrophie reste peu sensible.

<!-- factual: row:cand.e1.61bf7ced3b984f5e -->
Limites : Mesures indirectes dans plusieurs études; durées ~12 semaines.

<!-- factual: row:cand.e1.61bf7ced3b984f5e -->
Interprétation pratique : Périodiser pour gérer fatigue, préférences et double objectif force/hypertrophie, non parce qu’un modèle grossit forcément plus.

<!-- factual: row:cand.e1.61bf7ced3b984f5e -->
Ce qu’on ne peut PAS conclure : Une supériorité hypertrophique universelle de l’ondulatoire, linéaire ou blocs.

<!-- factual: row:cand.e1.ac1f53d2ed5adb31 -->
Affirmation principale : Les blocs peuvent être utiles pour prioriser une qualité, mais les données hypertrophie directes sont rares et mixtes.

<!-- factual: row:cand.e1.ac1f53d2ed5adb31 -->
Confiance : Faible

<!-- factual: row:cand.e1.ac1f53d2ed5adb31 -->
Population : 22 hommes entraînés dans un RCT récent

<!-- factual: row:cand.e1.ac1f53d2ed5adb31 -->
Sources principales : Bartolomei et al., 2023

<!-- factual: row:cand.e1.ac1f53d2ed5adb31 -->
Type de preuve : Petit RCT

<!-- factual: row:cand.e1.ac1f53d2ed5adb31 -->
Contradictions / nuances : Séances mixtes ont davantage amélioré masse maigre/épaisseur et bench; blocs davantage le saut, à volume égal.

<!-- factual: row:cand.e1.ac1f53d2ed5adb31 -->
Limites : 10 semaines; hommes; programmes particuliers.

<!-- factual: row:cand.e1.ac1f53d2ed5adb31 -->
Interprétation pratique : Employer blocs si cela simplifie les priorités ou la fatigue; conserver un minimum des qualités non prioritaires.

<!-- factual: row:cand.e1.ac1f53d2ed5adb31 -->
Ce qu’on ne peut PAS conclure : Qu’un bloc de spécialisation musculaire est supérieur à une organisation mixte.

<!-- factual: row:cand.e1.6bd63a9af49a8619 -->
Affirmation principale : La variation planifiée de volume et charge peut aider la gestion à long terme sans être une condition de l’hypertrophie.

<!-- factual: row:cand.e1.6bd63a9af49a8619 -->
Confiance : Modéré comme outil; faible comme avantage causal

<!-- factual: row:cand.e1.6bd63a9af49a8619 -->
Population : Tous

<!-- factual: row:cand.e1.6bd63a9af49a8619 -->
Sources principales : ACSM, 2026; Bernárdez-Vázquez et al., 2022

<!-- factual: row:cand.e1.6bd63a9af49a8619 -->
Type de preuve : Position stand; umbrella review

<!-- factual: row:cand.e1.6bd63a9af49a8619 -->
Contradictions / nuances : Programmes non périodisés progressifs fonctionnent.

<!-- factual: row:cand.e1.6bd63a9af49a8619 -->
Limites : « Périodisation » recouvre de nombreux modèles.

<!-- factual: row:cand.e1.6bd63a9af49a8619 -->
Interprétation pratique : Utiliser le modèle le plus simple compatible avec progression, récupération et calendrier.

<!-- factual: row:cand.e1.6bd63a9af49a8619 -->
Ce qu’on ne peut PAS conclure : Que complexité = efficacité ou qu’il faut changer les répétitions chaque semaine.

## Limites

<!-- editorial -->
Aucune de ces fiches n’a été relue par un humain. L’extraction est déterministe — aucun modèle génératif n’y intervient — mais la fidélité au document ne vaut pas validation scientifique.
